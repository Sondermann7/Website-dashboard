# Review-velocity scorecard per market

**Department:** Reputation & Reviews
**Frequency:** monthly
**Where:** Birdeye dashboard
**Owner:** Marketing operator (Claude Code / Cowork session) — approved by Mikey

## Objective

Target 8–12 new Google reviews/mo per market. Below pace two months running = fix the ask process.

## Procedure

1. Pull new-review count + avg rating per location.
2. Compare to target; flag markets below pace.
3. Adjust ask timing/channel where behind.
