# 30/60/90 gate check — jobs won, not rankings

**Department:** Competitive Intelligence & Measurement
**Frequency:** monthly
**Where:** Revenue Scorecard + GSC + CallRail
**Owner:** Marketing operator (Claude Code / Cowork session) — approved by Mikey

## Objective

Score against the Revenue Scorecard checkpoints. A Day-90 Boise miss = authority gap confirmed → shift budget from content to links.

## Procedure

1. Score every checkpoint pass/fail for the current gate.
2. Pull CallRail/GA4 organic-attributed Boise leads.
3. Count new referring domains vs 682 baseline.
4. Decide: stay course, or reallocate content budget to links.
