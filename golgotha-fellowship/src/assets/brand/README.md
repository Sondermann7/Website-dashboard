# Logo

Put the church's own original logo files here (PNG with transparency, or SVG):

- `logo`        - for light backgrounds (header)
- `logo-light`  - for dark backgrounds (footer). Optional.

Until a file is present the site shows the church name set in type. The logo is not
redrawn or recreated. The Calvary Chapel Association mark is an affiliation badge,
not the church logo - do not use it here.
