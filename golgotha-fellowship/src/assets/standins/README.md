# Stand-in images (preview only)

Free Adobe Stock photos used ONLY to preview the layout where the church has not yet
supplied a real photo (kids, youth, outreach, missions). They are not Golgotha
Fellowship and must never be published as if they were.

- They load only in the preview build: `npm run build:preview`.
- The normal build (`npm run build`) ignores this folder completely.
- The image files are git-ignored (stock files may not be redistributed in a public
  repository). A real photo with the same name in `src/assets/photos/` always wins.
